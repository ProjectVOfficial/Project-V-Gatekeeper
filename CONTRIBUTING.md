# Contributing

Project V // Gatekeeper is currently a **source-closed proprietary project**.

This public repository is intended for:

- release information
- documentation
- bug reports
- feature requests
- security reporting guidance
- installation and verification help

## Source Contributions

The Gatekeeper source tree is not maintained in this public repository, so normal public pull requests containing product source changes are not currently accepted.

Do not submit copied, reverse-engineered, or third-party proprietary source code.

## Bug Reports

When reporting a bug, include:

- Gatekeeper version
- Windows version
- installer or desktop-portable build
- whether Gatekeeper Core is installed and running
- what you expected to happen
- what actually happened
- minimal reproduction steps
- screenshots or logs with sensitive information removed

## Feature Requests

Feature requests are welcome. Please explain the use case and desired behavior rather than only naming a technology.

## Security Issues

Do not publish exploit details in a normal public issue.

See [SECURITY.md](SECURITY.md).
