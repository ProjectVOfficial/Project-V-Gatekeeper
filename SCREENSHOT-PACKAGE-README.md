# Project V // Gatekeeper Screenshot Package

This folder contains sanitized screenshots prepared for the public
`ProjectVOfficial/Project-V-Gatekeeper` repository.

## Notes

- Screenshots are representative of the Gatekeeper 1.0 RC1 / 1.0.0 UI.
- Public IP/endpoint values and user-specific local path fragments were redacted where visible.
- Process names, generic Windows paths, localhost addresses, and UI telemetry were retained because they help demonstrate Gatekeeper's functionality.
- Do not replace these sanitized images with raw screenshots unless you have reviewed them for credentials, personal paths, private IPs, tokens, or other machine-specific data.
